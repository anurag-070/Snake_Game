# Snake_Game
================
A modern implementation of the classic Snake game using HTML.

### Features
------------

* **Classic Gameplay**: Experience the nostalgic gameplay of the original Snake game
* **Simple and Intuitive Controls**: Use arrow keys to navigate the snake
* **Score Tracking**: Keep track of your high score

### Tech Stack
-------------

* **HTML**: Used for structuring and rendering the game
* **CSS**: Used for styling and layout (inline styles in `index.html`)
* **JavaScript**: Used for game logic and event handling (inline scripts in `index.html`)

### Installation
------------

1. Clone the repository: `git clone https://github.com/your-username/Snake_Game.git`
2. Open the `index.html` file in a web browser to play the game

### Usage
-----

1. Use the arrow keys to control the snake's direction
2. Eat the food pellets to grow the snake and increase your score
3. Avoid colliding with the wall or the snake's body to survive
